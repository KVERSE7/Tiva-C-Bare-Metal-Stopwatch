Tiva C Bare-Metal StopwatchThis repository contains a bare-metal embedded C stopwatch application designed for the Texas Instruments Tiva C Series microcontroller. Developed using Code Composer Studio (CCS), it leverages the TI TivaWare peripheral driver library to directly interface with hardware timers, GPIO interrupts, a character LCD, and UART.   FeaturesPrecise Timing: Tracks time with 10 ms precision using the SysTick hardware timer.   Interrupt-Driven Controls: Uses falling-edge GPIO interrupts for immediate, debounced-style response to button presses.   Start/Stop Toggle: SW1 controls the running state of the timer.   Lap Recording: SW2 captures the current time as a lap without stopping the main timer.   Visual Status Indication: Utilizes the onboard RGB LED to indicate running (Green), stopped (Red), and lap recorded (Blue flash) states.   LCD Display: Provides real-time formatted time ("MM:SS.cc") and the last recorded lap time on a 2-row character LCD.   UART Telemetry: Transmits live status messages (">> RUNNING", ">> STOPPED") and formatted timestamps to a PC serial terminal.   Hardware Requirements & Pin MappingMicrocontroller: TI Tiva C Series LaunchPad (e.g., TM4C123G).Display: HD44780-compatible Character LCD.   System Clock: Configured to a 16 MHz main oscillator.   Pin ConnectionsLCD Data Lines (D4-D7): Connected to GPIO Port D, Pins 0, 1, 2, and 3.   LCD Register Select (RS): Connected to GPIO Port E, Pin 2.   LCD Enable (E): Connected to GPIO Port E, Pin 3.   UART0 (RX / TX): Connected to GPIO Port A, Pins 0 and 1.   Onboard Buttons: Port F, Pin 4 (SW1) and Pin 0 (SW2) configured with weak pull-up resistors. Note: PF0 is a locked pin that is unlocked in software during initialization.   Onboard RGB LED: Port F, Pins 1 (Red), 2 (Blue), and 3 (Green).   Software RequirementsIDE: Texas Instruments Code Composer Studio (CCS).Dependencies: TI TivaWare for C Series. The project requires the driverlib and inc directories for hardware register mapping and peripheral control macros.   Project Development PhasesThe project was structured into four iterative phases to build and verify functionality sequentially:Phase 1: Basic LCD Setup (phase1.c)Initializes the LCD in 4-bit mode across two lines.   Displays a static "  STOPWATCH   " message on row 0 and "   READY...   " on row 1 to verify wiring.   Phase 2: SysTick Integration (phase2.c)Implements the SysTickHandler to generate interrupts every 10 milliseconds.   The timer starts automatically upon power-on and updates the formatted time on the top row of the LCD.   Phase 3: State Control (phase3.c)Introduces the button handler using GPIO interrupts for SW1.   Pressing SW1 toggles the timer between running and stopped states.   Illuminates the Green LED when running and the Red LED when stopped.   Phase 4: Complete Stopwatch (main.c)Unlocks and configures SW2 as an interrupt-driven input.   Pressing SW2 records the lap time, displays it on the second row of the LCD, and triggers an approximate 100-millisecond flash of the Blue LED.   Initializes UART communication to send continuous time updates and lap records to a PC.   Usage InstructionsWiring: Connect the character LCD to the designated Port D and Port E pins on the LaunchPad.   Build and Flash: Open the project in Code Composer Studio, compile the Phase 4 main.c code, and flash it to the LaunchPad.   Serial Terminal: Open a serial monitor (like PuTTY or Tera Term) on your PC and connect to the LaunchPad's COM port with the following settings: 115200 baud, 8 data bits, 1 stop bit, No parity.   Operation:Press SW1 to start the stopwatch.   Press SW2 while running to log a lap time to the LCD and serial terminal.   Press SW1 again to pause the timer.
